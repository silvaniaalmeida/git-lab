# Git Lab

Laboratório para aprendizado de Git e GitHub.

## Objetivo

Praticar os principais conceitos e comandos do Git.

## Como utilizar este laboratório

Este repositório é utilizado para praticar:
- Criação e gerenciamento de branches
- Controle de versões com commits
- Integração de alterações com merge
- Colaboração por meio de Pull Requests

## Tecnologias e ferramentas

- Git — controle de versões
- GitHub — hospedagem e colaboração
- Terminal macOS — execução dos comandos Git
- GitHub CLI (gh) — gerenciamento de repositórios e Pull Requests
- Markdown — documentação dos projetos
